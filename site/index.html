能力

只做计划任务，
把它做完整

不是又一个服务器面板。没有应用商店、网站管理和容器编排，只有一个二进制和它管好的那批任务。

01

两类任务，完整 cron

shell 脚本（bash / sh / python3 任一带解释器）和 curl 请求（多个 URL 依次访问）。5 段 cron 表达式，也支持 @every / @daily 快捷写法，多周期用 && 拼。

*/5 * * * *
0 3 * * * && 0 3 * * 0

02

脚本库，改一次全生效

可复用脚本集中管理，任务只引用不复制。脚本改了，引用它的所有任务立刻用上新的内容，无需重新保存任务。

运维巡检/prune.sh
↳ 3 个任务正在引用

03

崩了会自愈

服务重启时自动清理残留的执行中状态，恢复全部已启用任务的调度。被中断的记录会标上「interrupted by service restart」。

interrupted by service restart

刻意不做的部分

少即是这里的意思。每一项砍掉的东西，都换来了单二进制和零外部依赖。

  • 网站与 Nginx不做反向代理和虚拟主机配置
  • 应用商店不装 WordPress、数据库和 Java 应用
  • 数据库管理不内嵌数据库运维模块
  • 容器编排不拉镜像、不管 compose 项目
  • 告警通知不接邮件、飞书、企微等外推
  • AI Agent不带任何大模型对话能力

任务一键导出为 JSON，脚本库与执行记录随整站备份还原一起迁移——换机器、做灾备都不丢。

全部任务一键导出为 JSON 文件；导入时自动跳过重名任务，并统计成功、跳过与失败项，迁移整批配置不丢不重。

01

执行安装命令

在任意 Linux 服务器上以 root 或 sudo 运行。不带参数是交互式提问，指定任意参数则全程静默。

# 交互式
bash -c "$(curl -sSL https://raw.githubusercontent.com/
meimolihan/2Panel/main/scripts/install.sh)"

# 静默：指定端口与数据目录
bash -c "$(curl -sSL .../install.sh)" \
  -p 8080 -d /var/lib/2panel

02

打开地址，登录

首次启动生成随机默认密码，日志里能查到。登录后请立刻改掉它。

# systemd 方式
journalctl -u 2panel -n 20 | grep "default password"

# nohup 方式
grep "default password" data/2panel.log

# 或走状态接口（改密前可用）
curl -sS -X POST -H "Content-Type: application/json" -d '{}' \
  http://127.0.0.1:8080/api/auth/status

常见问题

装之前可能想问的

和 1Panel 的计划任务有什么区别？

2Panel 参考 1Panel 的计划任务功能重构，但砍掉了网站、应用商店、数据库管理、容器编排、告警、AI Agent 等无关模块，只保留 shell / curl 两类任务及执行记录。代价是没有全家桶，换来的是单个二进制、不装 Node、不用备数据库，任务调度和日志读起来也更直接。

需要装 Go、Node 或数据库吗？

都不需要。Go 只是构建期的依赖，发布的是编译好的二进制。运行时用 SQLite，驱动是纯 Go 实现，不需要 CGO 或 GCC。

任务能用现有的 crontab 吗？

可以，任务支持标准 5 段 cron 表达式，也支持 @every、@daily 这类快捷语法。已有的 crontab 行搬过来基本不用改写，只是从 crontab 文件挪到界面里，之后就有了历史和日志。

支持哪些系统？

Ubuntu、Debian、CentOS 等主流发行版，amd64 与 arm64 都有构建产物（SHA-256 校验）。有 systemd 的机器自动注册成常驻服务，没有的（比如容器里）回退成后台运行。

怎么备份和迁移？

两种方式：任务层面可一键导出 / 导入 JSON（导入自动跳过重名、统计失败项）；整站层面用 2panel backup / restore 或 Web 端「备份还原」，把管理员、任务、脚本库、执行记录打包成一个 zip，换机器直接还原。

怎么卸载？

一条命令即可，脚本会停服务、删二进制、关掉安装时开放的防火墙端口，并询问是否保留数据目录；加 --purge 才会连数据一起删。

卸载（保留数据目录）

bash -c "$(curl -sSL .../uninstall.sh)"

卸载（连数据一起删）

bash -c "$(curl -sSL .../uninstall.sh)" -y --purge

脚本会先停并移除 systemd 服务（或结束后台进程），再删除二进制、关闭防火墙端口，最后按提示处理数据目录。端口与数据目录自动从安装记录 / 服务文件 / 进程命令行解析，无需手动指定。
